# llm-introduction-phi3
My first practical project with Large Language Models using Microsoft Phi-3 and Hugging Face Transformers.

## Objective

Understand the basic workflow of an LLM and generate text using Microsoft's Phi-3 model.

## Technologies

- Python
- PyTorch
- Hugging Face Transformers
- Microsoft Phi-3
- Google Colab

## What I Learned

- What Large Language Models are
- What tokens and token IDs are
- How tokenizers work
- How to load a pretrained LLM
- How to use a text-generation pipeline
- How prompts affect the generated response

## Experiments

### 1. Progammer Joke

Prompt:

"Create a funny joke about progammer."

### 2. Oracle Database Explanation

Prompt:

"Explain what an Oracle database is to a beginner in simple words."

## Basic Workflow

Text → Tokenizer → Token IDs → LLM → Generated Token IDs → Tokenizer → Text

## Key Takeaway

The same pretrained LLM can perform different language-generation tasks by changing the prompt without retraining the model.
